Kiểm tra API backend thật

Trang dành cho người làm backend. Gọi các endpoint chỉ đọc của backend thật, rồi so cấu trúc JSON trả về với backend giả (cũng là cấu trúc mô tả trong API_CONTRACT). Thiếu field nào thì frontend sẽ hiện sai ở chỗ đó. Không ghi dữ liệu nào ngoài đăng nhập/đăng xuất.

Đỏ = field frontend cần mà backend không trả (phải sửa). Vàng = sai kiểu dữ liệu. Xám = field thừa (không sao). Giá trị null ở một bên được coi là khớp mọi kiểu.

Nên dùng tài khoản Manager: một số endpoint (tham số, audit, dashboard) chỉ Manager gọi được.
