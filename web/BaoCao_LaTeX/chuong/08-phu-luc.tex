\subsection{Hướng dẫn chạy hệ thống}

Máy cần có Docker (kèm Docker Compose v2), GNU Make và Git.

\begin{enumerate}
    \item Tải mã nguồn: \texttt{git clone} kho mã ở Bảng~\ref{tab:lien-ket}, chuyển sang nhánh
    \texttt{dev}.
    \item Tạo tệp cấu hình: \texttt{cp .env.example .env}, rồi thay các mật khẩu mẫu.
    \item Khởi động: \texttt{make start}. Giao diện ở \url{http://localhost:4200}, API ở
    \url{http://localhost:8000}.
    \item Tạo tài khoản thử và dữ liệu mẫu: \texttt{make demo-seed}; tài khoản được ghi ở
    \path{data/evidence/P12-DEMO-CREDENTIALS.env}.
    \item Dừng hệ thống: \texttt{make stop} (dữ liệu vẫn được giữ).
\end{enumerate}
